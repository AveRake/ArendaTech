# Формат совпадает с форматом файла, который Visual Studio подключает как
# AdditionalFiles (см. методические указания к лабораторной работе №3):
#     <правило>: <порог>
# Комментарии начинаются с символа «#».
#
# Правила:
#   CA1501 — избыточная глубина наследования (Depth of Inheritance);
#   CA1502 — избыточная сложность (Cyclomatic Complexity);
#   CA1505 — код трудно сопровождать (Maintainability Index, минимальное значение);
#   CA1506 — избыточная связанность классов (Class Coupling).
#
# Обоснование значений для Python-проекта «АрендаТех»:
#   CA1501 = 3 — иерархия пользователей в проекте двухуровневая
#                (Person → Student/Teacher/Employee), иерархия исключений —
#                двухуровневая (Exception → DomainError → подтипы); значение 3
#                допускает такие иерархии и предупреждает о дальнейшем росте.
#                Для сравнения: в .NET по умолчанию 6.
#   CA1502 = 10 — стандартное значение Microsoft: методы сложнее 10 трудно
#                покрывать тестами (нужно не менее CC тест-кейсов).
#   CA1505 = 20 — стандартное значение Microsoft: MI < 20 означает, что код
#                трудно сопровождать (красная зона).
#   CA1506 = 20 — для сервисного слоя значение выше стандартного (10), так как
#                фасад по определению агрегирует типы предметной области;
#                20 оставляет правило информативным и достижимым.
